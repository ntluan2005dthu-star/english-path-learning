📌 Tổng quan

English Path là một ứng dụng web chạy cục bộ trên máy cá nhân, dùng Flask làm backend và lưu toàn bộ dữ liệu học tập vào một file Excel duy nhất (data/english_learning_data.xlsx). Hệ thống được thiết kế cho một người học duy nhất — người Việt mới bắt đầu — hướng tới hai mục tiêu song song:

  • Tiếng Anh giao tiếp từ con số 0: chào hỏi, tự giới thiệu, số đếm, gia đình, trường học, sở thích, hội thoại tình huống, nghe, nói, đọc hiểu.
  • Tiếng Anh chuyên ngành CNTT: máy tính, hệ điều hành, mạng, lập trình, frontend, backend, cơ sở dữ liệu, kiểm thử, mô tả dự án.

Hệ thống tích hợp sẵn bộ từ vựng mẫu và tính năng tự động tải 5000 từ vựng chuẩn Oxford trực tiếp từ internet để mở rộng kho từ. Lộ trình gợi ý 6 tháng chia thành 24 bài, có thể điều chỉnh tốc độ.

Đối tượng phù hợp: người Việt mới học tiếng Anh, sinh viên CNTT hoặc người chuyển ngành muốn chuẩn bị vốn tiếng Anh cho công việc lập trình. Không dành cho lớp học đông người hoặc môi trường nhiều người dùng cùng lúc.

✨ Tính năng chính

🗺️ Lộ trình 6 tháng

  • 24 bài học chia đều 6 tháng.
  • Mỗi bài gắn 1 kỹ năng: nghe, nói, đọc, ngữ pháp, từ vựng, IT.
  • Bài tiếp theo tự động mở khoá khi hoàn thành bài trước.

📚 Thư viện từ vựng

  • Tích hợp 5000 từ Oxford: Nhấn nút trên web để tự động tải và thêm vào Excel.
  • Lưu trữ IPA, từ loại, nghĩa Việt, định nghĩa Anh, câu ví dụ, CEFR, độ khó, nguồn.
  • Tìm kiếm, lọc, đánh dấu yêu thích, cập nhật trạng thái.
  • Phát âm bằng Web Speech API.

📝 Trung tâm kiểm tra

  • Sinh đề theo chủ đề (5–20 câu).
  • Các dạng: Anh→Việt, điền khuyết, nghe.
  • Chỉ hiện đáp án sau khi nộp. Kết quả lưu vào TestResults.

❌ Sổ lỗi sai & 📊 Thống kê

  • Lưu lại câu sai, số lần sai, cho phép đánh dấu "đã khắc phục".
  • Thống kê chuỗi ngày học, phút học, điểm trung bình dựa trên dữ liệu thật.
  • Thuật toán ôn tập ngắt quãng (SRS) 1/3/7/14/30 ngày.

🚀 Cài đặt và chạy trên Windows

Mở PowerShell tại thư mục dự án và chạy lần lượt các bước sau:

1
Tạo môi trường ảo
python -m venv venv .\venv\Scripts\Activate.ps1
2
Cài thư viện
pip install -r requirements.txt
3
Chạy ứng dụng
python app.py

Mở trình duyệt và truy cập: http://127.0.0.1:5000

📂 Cấu trúc thư mục

english_path/ ├── app.py # Backend Flask, điều hướng, API ├── requirements.txt # Flask==3.0.3, openpyxl==3.1.5 ├── data/ │ ├── english_learning_data.xlsx # Tự sinh khi chạy lần đầu │ └── backups/ # Sao lưu tự động mỗi lần ghi ├── modules/ │ ├── excel_store.py # Đọc/ghi Excel an toàn │ ├── online_loader.py # Tải 5000 từ Oxford │ ├── quiz_engine.py # Sinh câu hỏi & chấm điểm │ ├── seed_data.py # Dữ liệu mẫu ban đầu │ └── srs.py # Thuật toán lặp lại ngắt quãng ├── templates/ # Các file HTML giao diện └── static/ # CSS và JS

📊 Thiết kế dữ liệu Excel

Toàn bộ trạng thái ứng dụng nằm trong một workbook english_learning_data.xlsx, gồm 10 sheet có schema cố định:

Sheet Mục đích
Vocabulary Kho từ vựng (có thể lên tới 5000+ dòng nếu nhập Oxford)
Phrases Câu hội thoại mẫu
Grammar Chủ điểm ngữ pháp
Lessons Bài học trong lộ trình
Exercises Bài tập gắn với lesson
TestResults Lịch sử làm bài
StudyProgress Tiến độ từng ngày
Mistakes Sổ lỗi sai
Sources Danh sách nguồn tham khảo
Settings Cấu hình hệ thống
Lưu ý: Excel không phải là cơ sở dữ liệu. Khi nhập 5000 từ Oxford, file Excel sẽ phình to và tốc độ đọc/ghi sẽ chậm hơn. Nó phù hợp cho học cá nhân, không phù hợp cho nhiều người dùng cùng lúc.

🔌 API endpoints

Method Route Chức năng
GET /api/dashboard Số liệu tổng hợp cho trang chủ
GET /api/vocabulary Tìm kiếm, lọc, phân trang từ vựng
POST /api/vocabulary/import-oxford Tự động tải và import 5000 từ Oxford
POST /api/quiz/submit Chấm điểm, lưu kết quả, ghi lỗi sai, cập nhật SRS
GET /api/stats Toàn bộ số liệu thống kê

🛡 An toàn dữ liệu & Giới hạn

  • Sao lưu tự động: Mỗi lần ghi thành công, file cũ được copy sang data/backups/.
  • Atomic save: Ghi file tạm rồi dùng os.replace() để thay thế, tránh hỏng file nếu mất điện.
  • Khoá ghi: Dùng threading.Lock() tránh xung đột dữ liệu.
  • Giới hạn: Chỉ hỗ trợ 1 người dùng, chưa tích hợp nhận dạng giọng nói chấm điểm phát âm, chưa có tính năng export CSV hay migrate sang SQLite.
