📌 Tổng quan

English Path là một ứng dụng web chạy cục bộ trên máy cá nhân, dùng Flask làm backend và lưu toàn bộ dữ liệu học tập vào một file Excel duy nhất (data/english_learning_data.xlsx). Hệ thống được thiết kế cho một người học duy nhất — người Việt mới bắt đầu — hướng tới hai mục tiêu song song:

  • Tiếng Anh giao tiếp từ con số 0: chào hỏi, tự giới thiệu, số đếm, gia đình, trường học, sở thích, hội thoại tình huống, nghe, nói, đọc hiểu.
  • Tiếng Anh chuyên ngành CNTT: máy tính, hệ điều hành, mạng, lập trình, frontend, backend, cơ sở dữ liệu, kiểm thử, mô tả dự án.

Hệ thống tích hợp sẵn bộ từ vựng mẫu và tính năng tự động tải 5000 từ vựng chuẩn Oxford trực tiếp từ internet để mở rộng kho từ. Lộ trình gợi ý 6 tháng chia thành 24 bài, có thể điều chỉnh tốc độ. Hệ thống không cam kết người học đạt mức lưu loát sau 6 tháng — đây chỉ là khung tham khảo.

Đối tượng phù hợp: người Việt mới học tiếng Anh, sinh viên CNTT hoặc người chuyển ngành muốn chuẩn bị vốn tiếng Anh cho công việc lập trình. Không dành cho lớp học đông người hoặc môi trường nhiều người dùng cùng lúc.

✨ Tính năng chính

🗺️ Lộ trình 6 tháng

  • 24 bài học chia đều 6 tháng.
  • Mỗi bài gắn 1 kỹ năng: nghe, nói, đọc, ngữ pháp, từ vựng, IT.
  • Bài tiếp theo tự động mở khoá khi hoàn thành bài trước.

📚 Thư viện từ vựng

  • Tích hợp sẵn 5000 từ Oxford: Nhấn nút "Nhập 5000 từ Oxford" để tự động tải và thêm vào Excel.
  • Mỗi từ lưu: IPA, từ loại, nghĩa Việt, định nghĩa Anh, collocation, câu ví dụ, chủ đề, CEFR, độ khó, nguồn tham khảo.
  • Tìm kiếm Anh ↔ Việt, lọc theo chủ đề / độ khó / trạng thái, đánh dấu yêu thích, đánh dấu đã thành thạo.
  • Phát âm bằng Web Speech API của trình duyệt.

📅 Luyện tập hằng ngày (40 phút)

  • 5 phần: ôn từ đến hạn, học từ mới, nghe & phát âm, đọc hội thoại, kiểm tra 5 câu.
  • Trạng thái từng phần được lưu vào StudyProgress theo ngày.

📝 Trung tâm kiểm tra

  • Sinh đề theo chủ đề, chọn 5–20 câu.
  • Các dạng: Anh→Việt, Việt→Anh, điền khuyết, nghe.
  • Chỉ hiện đáp án + giải thích sau khi nộp.
  • Kết quả lưu vào TestResults.

❌ Sổ lỗi sai

  • Lưu mọi câu sai: câu hỏi, đáp án bạn chọn, đáp án đúng, số lần sai, giải thích.
  • Đánh dấu "đã khắc phục" khi hiểu.
  • Có thể lọc xem lỗi chưa/đã xử lý.

🎧 Luyện nghe & 🎤 Luyện nói

  • Nghe từ và chọn đáp án đúng (dùng Web Speech API).
  • Luyện nói: phát mẫu câu, tự đọc theo, tự đánh giá (không chấm điểm phát âm).

📊 Thống kê & 🎯 Mục tiêu

  • Chuỗi ngày học, phút học, điểm trung bình, từ vựng theo chủ đề, điểm yếu.
  • Mọi con số đều tính từ dữ liệu thật trong Excel — không có số liệu giả.

🚀 Cài đặt và chạy trên Windows

Các bước dưới đây dùng PowerShell (không phải CMD). Mở PowerShell tại thư mục dự án.

1
Cài Python 3.10+ (nếu chưa có)
Tải từ python.org/downloads và tick chọn "Add python.exe to PATH" khi cài.
python --version # Kết quả mong đợi: Python 3.11.x trở lên
2
Tạo môi trường ảo (venv)
Cô lập thư viện của dự án, tránh xung đột với các dự án Python khác.
python -m venv venv .\venv\Scripts\Activate.ps1
Khi kích hoạt thành công, prompt sẽ có tiền tố (venv). Nếu bị lỗi Activate.ps1 cannot be loaded, chạy một lần: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.
3
Cài thư viện
Cài Flask và openpyxl theo đúng phiên bản trong requirements.txt.
pip install -r requirements.txt
4
Chạy ứng dụng
Flask sẽ tự tạo file Excel và khởi động server tại cổng 5000.
python app.py
Lần chạy đầu tiên sẽ tạo data/english_learning_data.xlsx (10 sheet với dữ liệu mẫu).
5
Mở trình duyệt
Truy cập địa chỉ sau (dùng Chrome / Edge / Cốc Cốc để Web Speech API hoạt động):
http://127.0.0.1:5000

Khắc phục sự cố thường gặp

Lỗi Nguyên nhân Cách xử lý
python not found Python chưa cài hoặc chưa vào PATH Cài lại, tick "Add Python to PATH"
Activate.ps1 cannot be loaded Execution policy chặn script Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
TemplateNotFound Chạy app.py từ sai thư mục cd vào thư mục gốc có templates/ trước khi chạy
Port 5000 đang bận Cổng đã bị dùng Đổi port=5000 trong app.py sang 5001
PermissionError khi ghi Excel File Excel đang mở trong Microsoft Excel Đóng file Excel rồi tải lại trang

📊 Thiết kế dữ liệu Excel

Toàn bộ trạng thái ứng dụng nằm trong một workbook english_learning_data.xlsx, gồm 10 sheet có schema cố định:

Sheet Mục đích Cột chính
Vocabulary Kho từ vựng (có thể lên tới 5000+ dòng nếu nhập Oxford) id, word, ipa, pos, vi_meaning, en_definition, example_en, example_vi, topic, cefr, difficulty, source_name, source_url, status, next_review, interval_days, ease
Phrases Câu hội thoại mẫu id, phrase_en, phrase_vi, topic, source_name, source_url
Grammar Chủ điểm ngữ pháp id, title_vi, title_en, content_vi, example_en, example_vi, level, source_url
Lessons Bài học trong lộ trình id, month, title_vi, title_en, skill, description_vi, estimated_minutes, unlock_order, vocab_topics
Exercises Bài tập gắn với lesson id, lesson_id, type, question, options, answer, explanation_vi, vocab_id
TestResults Lịch sử làm bài id, date, quiz_type, lesson_id, total, correct, score, duration_sec, details
StudyProgress Tiến độ từng ngày id, date, tasks_done, new_words, reviewed_words, quiz_score, minutes
Mistakes Sổ lỗi sai id, qid, question, user_answer, correct_answer, explanation_vi, knowledge_point, wrong_count, resolved
Sources Danh sách nguồn id, name, url, type, verified
Settings Cấu hình hệ thống id, key, value, note
Excel không phải là cơ sở dữ liệu. Khi nhập 5000 từ Oxford, file Excel sẽ phình to (khoảng 2-4 MB) và tốc độ đọc/ghi sẽ chậm hơn so với ban đầu. Nó phù hợp cho học cá nhân, không phù hợp cho ghi đồng thời nhiều người.

🔌 API endpoints

Tất cả dữ liệu đi qua backend; trình duyệt không đọc/ghi trực tiếp file Excel.

Method Route Chức năng
GET /api/dashboard Số liệu tổng hợp cho trang chủ
GET /api/roadmap Danh sách bài học theo tháng + trạng thái mở khoá
GET /api/lesson/<id> Chi tiết 1 bài học
POST /api/lesson/<id>/complete Đánh dấu hoàn thành bài học
GET /api/vocabulary Tìm kiếm, lọc, phân trang từ vựng
POST /api/vocabulary/import-oxford Tự động tải và import 5000 từ Oxford
POST /api/vocabulary/<id>/favorite Bật/tắt yêu thích
POST /api/vocabulary/<id>/status Đổi trạng thái (new / learning / reviewing / mastered)
POST /api/vocabulary/<id>/review Cập nhật SRS theo kết quả đúng/sai
GET /api/daily Nhiệm vụ hôm nay + tiến độ
POST /api/daily/complete Đánh dấu 1 nhiệm vụ đã xong
GET /api/grammar · /api/phrases · /api/it-english Dữ liệu cho các trang tương ứng
POST /api/quiz/generate Sinh đề theo chủ đề / lesson / số câu
POST /api/quiz/submit Chấm điểm, lưu kết quả, ghi lỗi sai, cập nhật SRS
GET /api/mistakes?resolved=0|1 Danh sách lỗi sai
POST /api/mistakes/<id>/resolve Đánh dấu đã khắc phục
GET /api/stats Toàn bộ số liệu thống kê
GET/POST /api/settings Đọc/ghi cấu hình

🛡 An toàn dữ liệu & Giới hạn

  • Sao lưu tự động: Mỗi lần ghi, file cũ được copy sang data/backups/.
  • Atomic save: Ghi file tạm rồi thay thế, tránh hỏng file nếu mất điện.
  • Khoá ghi: Dùng threading.Lock() tránh xung đột.
  • Giới hạn: Chỉ 1 người dùng, chưa hỗ trợ nhận dạng giọng nói, chưa có migration sang SQLite.
